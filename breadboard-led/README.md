# breadboard-led

STM32 project for the Nucleo F446RE.

## Hardware
- Board: NUCLEO-F446RE
- PA_10 connected to positive side of LED and negative side of LED connected to ground on nucleo.

## What it does
When onboard blue button is pressed it turns on the LED.

## How to build
Open in STM32CubeIDE and build with Debug configuration.
